# TurboSMS Reporter

[![Python Version](https://img.shields.io/badge/python-3.13+-blue.svg)](https://www.python.org/downloads/)
[![Platform](https://img.shields.io/badge/platform-Windows%20%7C%20Linux-lightgrey.svg)]()
[![License](https://img.shields.io/badge/license-MIT-green.svg)](LICENSE)

**TurboSMS Reporter** - зручна GUI утиліта для автоматизованого формування звітів з витрат на відправлені СМС-повідомлення з turbosms.ua за обраний період часу. 
Програма парсить дані зі сторінки, використовуючи діючий PHPSESSID користувача. Фіксує витрати на СМС, зміст яких співпадає з пошуковими шаблонами, введеними користувачем. Має опцію розрахунку витрат на повідомлення, які не співпали з пошуковими шаблонами. Звіти зберігаються в .xlsx файлах. 

---

## Особливості

* **Простий та інтуїтивно зрозумілий GUI**
* **Повна підтримка клавіатурної навігації** 
* **Відформатовний експорт в Excel**
* **Вбудований пошук за співпадінням змісту СМС**
* **Опція розрахунку витрат на повідомлення, які не співпали за змістом**
* **Працює однаково на Windows та на Linux**

## Інструкція з використання

1. **Оновлення авторизації (`PHPSESSID`)**:

    * Натисніть кнопку **"Оновити PHPSESSID"**.
    * Авторизуйтесь на сайті [turbosms.ua](https://turbosms.ua/).
    * Відкрийте інструменти розробника (`F12`) -> вкладка **Application / Storage -> Cookies**.
    * Скопіюйте значення ключа `PHPSESSID` та вставте його у відповідне поле програми.

2. **Налаштування шаблонів**

    * Натисніть **"Шаблони пошуку"** для додавання, редагування або видалення текстових фрагментів, за якими потрібно підраховувати витрати.

3. **Формування звіту**

    * Вкажіть часовий інтервал у форматі `ДД.ММ.ГГГГ ЧЧ:ММ` (наприклад, `01.10.2026 00:00`).
    * За потреби активуйте чекбокс **"Порахувати витрати поза шаблонами"**.
    * Натисність **"Сформувати звіт"** та оберіть шлях для збереження `.xlsx` файлу.

## Структура проєкту

    ├── calculator.py   # Модуль обчислень
    ├── exporter.py     # Модуль генерації та форматування Excel-звітів (openpyxl)
    ├── main.py         # Оркестрація даних, завантаження/збереження конфігурацій
    ├── parser.py       # Веб-парсер HTTP-запитів до TurboSMS (requests, BeautifulSoup)
    └── view.py         # Графічний інтерфейс користувача (wxPython)

## Завантаження та встановлення

Пропонуємо завантажити скомпільований бінарний файл для вашої ОС зі сторінки **[Latest Release](https://github.com/AmonRadii/turbosms-reporter/releases/latest)**

### Linux

* **Debian / Ubuntu (.deb package):**

  Завантажте `.deb` файл з Releases, відкрийте папку з ним та встановіть через термінал:

    ```bash
     sudo dpkg -i turbosms_reporter_*_amd64.deb
    ```

    або

    ```bash
     sudo apt install ./turbosms-reporter_*_amd64.deb
    ```

  Запустіть програму через термінал за допомогою команди `turbosms-reporter` або через меню додатків за назвою **TurboSMS Reporter**.


* **Інші дистрибутиви (Portable `.tar.gz`):**

    1. Завантажте архів **`TurboSMS_Reporter_Linux.tar.gz`**.
    2. Розпакуйте його в потрібну директорію:

        ```bash
         mkdir -p ~/turbosms-reporter
         tar -xzvf TurboSMS_Reporter_Linux.tar.gz -C ~/turbosms-reporter
         cd ~/turbosms-reporter
        ``` 

    3. Запустіть програму з терміналу:

        ```bash
         ./TurboSMS_Reporter
        ```

### Windows

1. Завантажте архів **`TurboSMS_Reporter_Windows.zip`**.
2. Розпакуйте вміст архіву в будь-яку зручну папку на комп'ютері.
3. Переконайтеся, що файли `search_templates.json` та `cookies.json` знаходяться в одній папці поруч із файлом `TurboSMS_Reporter.exe`.
4. Запустіть програму дабл-кліком по **`TurboSMS_Reporter.exe`**.
